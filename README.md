# FuelFit

A fitness e-commerce frontend for apparel, supplements, and workout accessories, built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a web browser. No build or package installation is required. An internet connection is needed for Google Fonts and externally hosted product images.

## Files

- `index.html`: main website, copied from the local `WEB PROJECT/1st.html`.
- `2nd.css`: website styles.
- `3rd.js`: product browsing, search, cart, and browser-based account interactions.
- `archive/`: earlier standalone FuelFit designs.

## Scope

This is a frontend demonstration. Account and cart state are handled in the browser. It does not provide a backend, production authentication, payment processing, or order fulfillment. Do not use real passwords in the demo account forms.

The original downloaded files have been preserved on the PC.
